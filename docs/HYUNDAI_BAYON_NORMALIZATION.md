# Hyundai BAYON variant normalization — evidence notes

Checked: 2026-11-06

## Deliverable

- `data/hyundai-bayon-variant-structure.csv`: 11 exact trim/transmission combinations from the current features matrix and the October 26, 2026 launch announcement.
- No variant-level price CSV is created because the launch announcement provides a starting price but not exact prices for all 11 combinations.

## Current OEM engine and trim plan

The current features matrix lists HX 2, HX 3, HX 3+, HX 5, HX 6, HX 8 and HX 10.

Engine: 1.5 l MPi Petrol.

- 6-speed manual: HX 2, HX 3, HX 3+, HX 5, HX 6, HX 8, HX 10 (7 combinations).
- Intelligent Variable Transmission (iVT): HX 5, HX 6, HX 8, HX 10 (4 combinations).

Total: 11 combinations. Hyundai's October 26, 2026 launch announcement independently confirms the same trim/transmission matrix. The current catalogue classifies BAYON as an SUV and the official homepage confirms the 1.5 l MPi engine and 6-speed MT / iVT options.

## Price evidence

The October 26, 2026 launch announcement states a starting ex-showroom price of ₹9,99,900. The current model catalogue shows a broad range of ₹9.99–18.14 lakh, which appears to include model-level or listing scope beyond the launch starting price. Neither is a complete variant price table, so no price is assigned to individual combinations. Current city-specific prices require official selector/dealer confirmation.

## Model-year note

The owner-manual selector lists BAYON from October 2026 to present, but no model-year value is assigned to individual variants because the engine/trim matrix does not state a model-year field.
