## Current India configuration

Toyota's current showroom presents one Camry Hybrid configuration. It uses the 2.5 l Dynamic Force four-cylinder petrol engine with fifth-generation Toyota hybrid technology and a high-capacity lithium-ion battery. The current technical specification lists 169 kW (230 PS) total hybrid output, 137 kW (187 PS) engine output, 100 kW (136 PS) motor output, 208 Nm motor torque and e-CVT transmission. The car is a 5-seat sedan with 2WD.
