## Current official evidence

Audi India currently lists the **New Audi RS Q8 SUV Performance**. The official India page specifies a 4.0L twin-turbo V8 TFSI petrol engine, 471 kW / approximately 640 PS, 850 Nm, quattro all-wheel drive and 0–100 km/h in 3.6 seconds. The optional Dynamic Package Plus raises top speed to 305 km/h.
