## Current variant structure

Tata.ev's current price page lists XE, XT, XZ+ and XZ+ LUX. All use a 26 kWh battery, Permanent Magnet Synchronous Motor, 55 kW / 75 PS, 170 Nm, front-wheel drive, automatic transmission and 5-seat sedan body. The official support page confirms 315 km MIDC P1+P2 range for the 26 kWh Tigor.ev.

## Price

Tata.ev's current product page states a starting ex-showroom price of ₹12,49,000. The page does not expose a numeric price for each of the four grades in the captured content, so this is retained as model-level starting price only. Autocar's September 2026 variant page lists on-road Hyderabad prices and is not used as ex-showroom variant pricing.
