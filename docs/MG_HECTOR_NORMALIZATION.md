## Current 2026 Storm editions

MG's October 7, 2026 official release lists HECTOR BLACKSTORM and HECTOR SNOWSTORM, each in a 5-seater configuration with a 1.5-litre turbo petrol engine and CVT transmission. Both are priced at ₹19,99,800 ex-showroom. These are current limited editions and are captured as distinct retail configurations.

## Broader Hector powertrain families

MG's December 15, 2025 all-new Hector release confirms 1.5 l turbo petrol with MT and CVT, and says diesel would be introduced in 2026. MG's price-matrix PDF includes 2.0 l diesel MT as a powertrain family. The current configurator extraction only exposes a selected Savvy Pro CVT build and does not provide a readable full trim/powertrain table. Therefore no full grade-to-powertrain matrix is invented. Hector's 5-, 6- and 7-seat configurations must remain distinct; this partial file only covers the two Storm editions whose 5-seat layout is explicitly stated.

## Price scope

The two Storm editions are both ₹19,99,800 ex-showroom, effective October 7, 2026. Older price matrix values are not treated as current without a current official grade-wise list.
